# Materials and methods

## Data

**Human Connectome Project (HCP) Young Adult, S1200 release**
(https://www.humanconnectome.org/study/hcp-young-adult): ~1 200 healthy adults
(22–35 y). We use the minimally preprocessed resting-state fMRI (4 runs,
14.4 min each, TR = 0.72 s) and the seven task fMRI batteries (working memory,
gambling, language, motor, relational, social, emotion). All analyses use the
HCP "FIX-cleaned" (ICA-based artefact removal) data. Access requires a free
Data Use Agreement at https://db.humanconnectome.org/.

## Parcellation

Cortical signals are averaged within the **Glasser MMP1.0 atlas** (360 parcels,
180 per hemisphere; Glasser et al., 2016, *Nature* 536:171), mapped to
fsLR32k surface space. The 360-node spectrum gives a good bulk (≈340 spacings
after edge trimming) while keeping per-parcel time series well averaged.
Robustness is checked with the Schaefer-200 volumetric atlas
(https://github.com/ThomasYeoLab/CBIG/tree/master/stable_projects/brain_parcellation/Schaefer2018_LocalGlobal).

## FC construction

1. Demean and standardise each parcel time series per run.
2. Band-pass 0.01–0.10 Hz (rest convention; tasks additionally
   block-regressed with the standard task design files to remove mean evoked
   responses, following Cole et al., 2014 — "background connectivity").
3. Pearson correlation across parcels → symmetric matrix C (Fisher-z values
   are used for second-level statistics, raw r for eigen-decomposition).
4. Rest FC: concatenate the 4 rest runs' cleaned series before correlating
   (and per-run for reliability analyses). Task FC: per-task concatenation of
   that task's 2 runs.

## Spectral statistics

All implemented in `src/spectral_chaos/spectral.py` with Google-style
docstrings and unit-tested anchors:

- `sorted_eigenvalues(C)` — eigvalsh on the symmetric FC matrix.
- **Bulk selection**: drop the largest eigenvalue (global mean mode) and the
  outer 5% at each edge; sensitivity analyses vary the trim.
- `spacing_ratios(evals)` — Oganesyan–Huse r_i on the *raw* spectrum.
- `mean_spacing_ratio` — ⟨r⟩; bootstrap CI (10 000 resamples over ratios).
- `unfold_spectrum` — polynomial (degree 7) fit to the empirical staircase;
  used for the spectral form factor and Wigner-surmise fits.
- `spectral_form_factor` — K(τ) = |Σ_j exp(−2πi e_j τ)|²/N on unfolded levels.
- `wigner_surmise_pdf(beta)` — for fitting an effective repulsion exponent β
  to the unfolded spacing histogram (maximum likelihood, β grid 0–2).

## Null models (essential)

1. **Phase randomisation (IAAFT-lite)**: Fourier-transform each parcel series,
   randomise the phases of each parcel *independently* (preserving
   each parcel's own power spectrum but destroying cross-parcel synchrony),
   and invert.
2. **Time-shift null**: circularly shift each parcel series by a random lag
   (preserves autocorrelation exactly, destroys sync).
3. **Wishart degrees-of-freedom null**: synthetic covariance matrices with the
   same T/p ratio as each scan — quantifies the finite-sample floor of ⟨r⟩,
   because (as our tests demonstrate) even pure-noise covariance matrices
   repel levels in the bulk.
4. **Length-matched rest null**: rest runs trimmed to each task's duration, to
   separate "task effect" from "fewer time points effect".

Every empirical ⟨r⟩ is reported **together with its four null distributions**
(z-score + percentile).

## Statistical testing

- **H1 (state)**: linear mixed model ⟨r⟩ ~ state + (1|subject) + motion +
  effective T; contrast task vs rest across 7 tasks (Bonferroni over tasks).
- **H2 (fingerprint)**: ICC(2,1) of ⟨r⟩ across the 2 rest days; and a
  Finn-style identification analysis (can a subject's day-2 spectrum be
  matched to their day-1 spectrum among all subjects?).
- **H3 (behaviour)**: ridge regression of task accuracy on ⟨r⟩_task,
  controlling age, motion, mean FC; 10-fold cross-validation, permutation
  p-values (5 000 shuffles).

## Reproducibility

- Python ≥ 3.10, `numpy`, `scipy`, `pandas`, `nilearn`, `statsmodels`.
- `tests/` must pass before any analysis branch is merged (16 anchors).
- All random seeds fixed and logged; figures regenerated by one script.
